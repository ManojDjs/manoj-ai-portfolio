# Manoj DJS — AI portfolio

A responsive personal portfolio for Manoj DJS, Technical Lead working on AI products. Built with semantic HTML, CSS and vanilla JavaScript. No build tools, dependencies or backend required.

## Local development

Run `python3 -m http.server 4173` from this directory, then visit http://localhost:4173.

Edit `index.html` for content, `styles.css` for layout, and `script.js` for interactions. Assets use relative paths so the site supports a GitHub Pages project URL.

## Deploy to GitHub Pages later

In GitHub, go to **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/ (root)**, then save. A public repository supports Pages on GitHub Free; private repository availability depends on your GitHub plan. Deployment has not been enabled as part of this work.

## Design

The visual reference is `concept.png`. The chrome artwork in `hero-knot.png` was generated using the built-in image generation tool. Native HTML renders all text and controls. The generated design reference contains illustrative technology marks; the implementation uses lightweight code-native marks with readable labels. The copy-email control is an intentional accessibility and usability addition.

The page reflects the supplied technical lead role and skills from the original portfolio. Add detailed AI project case studies when real project information is available.
